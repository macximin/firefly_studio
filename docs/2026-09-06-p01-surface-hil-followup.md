# p01 표면 유사성 HIL 접수와 후속 변주

2026-09-06

사람은 「회귀한 재벌 3세는 제 몫부터 챙긴다」 p01을 **보류**했다. Storyyard에 남긴 판단의 핵심은 다음과 같다.

> 다 좋은데, 표면이 너무 독식하는 재벌 3세다. 다른 작품들도 참고하거나, 믹스 혹은 변주가 필요하다.

코멘트에서 지목한 것은 1화 연회와 납품업자·입학 선물, 2화 네 명의 실행자 영입, 3화 220억 원 일본 투자와 조기 진학의 배치다. 기획의 자기 목적과 주인공 배경을 출발점으로 쓰되, 이 사건 묶음을 완성 작품으로 선택한 것은 아니다.

## 처리한 내용

- Storyyard 실제 결정 원본을 읽고 최신 패킷·후보 해시를 대조했다. 이전 p01에 남긴 양식 코멘트와 이번 보류를 섞지 않았다.
- InkOS 네이티브 `pitch decision`으로 **hold와 코멘트 전문을 그대로 기록**했다. 새 선택이나 원고 승인으로 바꾸지 않았다.
- 최신 기획서·slate·독립 심사·Storyyard 패킷의 바이트가 유지되는지 확인했다.
- 기존 사건 변주 연구와 금융형·사업형 후보를 검토했다. 기존 후보는 더 이른 p01을 바탕으로 하므로 최신 주인공 배경까지 검증된 결과로 취급하지 않는다.
- 최신 p01에서 후보를 추출해 새 변주 요청을 준비했다. 기존 원문 3작품의 사건 6개를 해시·행 범위·인용으로 다시 결속했다. **새 후보 생성과 독립 심사는 아직 실행하지 않았다. 이번 처리의 모델 호출은 0회다.**

## 현재 상태

InkOS에는 사람의 보류가 기록돼 있다. Storyyard의 v3 기획 판정에는 아직 처리 완료 영수증을 자동으로 되돌리는 경로가 없어 원격 처리 상태는 `pending`을 유지한다. 이는 사람의 보류가 없다는 뜻이 아니다. 원고용 v1 적용 API로 대신 종료하지 않았다.

후속 순서는 준비된 요청의 두 후보 생성 → 원문과 별도 비교 심사 → 변주 비교 HIL이다. 변주 방향이 정해진 뒤 기획서 전체와 연대·자금·인물의 후속 인과를 맞춘다. 현재 Book·A/B레일 정사·원고를 생성하거나 Storyyard를 재배포하지 않았다.
