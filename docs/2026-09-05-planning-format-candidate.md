# Firefly 작품 기획·Arc·회차 메모 양식 후보

2026-09-05 · 내부 검토용 · 정본/승인/생산 규칙 아님

[출처 비교와 적용 판단](/Users/a2501/Desktop/firefly_studio/docs/2026-09-05-industry-planning-templates-research.md)을 바탕으로 새로 쓴 양식이다. 한경의 기획 목차, 텐북의 간결한 작품 소개, 연속극 바이블과 장면 메모의 표현 방식을 참고했다. 실제 작품에 적용할 때는 기존 InkOS 문서의 해당 항목으로 옮기며 중복 정본을 만들지 않는다.

대괄호는 채울 자리다. 필요한 질문만 사용하고 분량·인물 수·장면 수를 일률적으로 고정하지 않는다. 첫 작성 때 모든 미래 사건을 확정할 필요는 없다.

| 질문 | 내용 |
| --- | --- |
| WHY: 왜 원하는가? | [주인공에게 이것을 얻는 일이 왜 좋은가] |

주인공의 목표를 작가의 주제 의식과 혼동하지 않는다. 특정 사람의 인정이나 내적 성장은 작품이 필요로 할 때 사용한다. 돈과 권한을 지운 뒤에도 말이 남는지만으로 목적의 적합성을 판단하지 않는다.

## B. 현재 Arc 카드

작품 설계의 큰 사건 구간과 InkOS의 1~3화 실행 ArcPacket을 구분한다. 아래 카드의 대상이 무엇인지 먼저 적는다.

- 대상 구간·회차: [구간 이름 / 실행 패킷 범위]
- 연결되는 장기 목적: [A의 무엇을 진전시키는가]
- 시작 상태: [주인공이 이미 알고·가지고·할 수 있는 것]
- 이번 목적: [구간이 끝날 때 얻으려는 결과]
- 핵심 선택과 HOW: [스스로 무엇을 선택하고 어떤 우위를 쓰는가]
- 사건의 연결: [그 선택 때문에 무엇이 일어나고 다음 행동으로 이어지는가]
- 지급·후과: [독자가 확인하는 성취 또는 착지하는 변화]
- 사람에게 보이는 결과: [누가 실제로 어떤 행동을 하는가]
- 끝 상태: [달라진 자원·관계·정보·상황]
- 남길 질문 또는 닫을 약속: [이번 구간의 의도에 맞게 선택]
- 참고 기능과 필요한 선행 설정: [자료를 썼다면 연결]

매번 실패·굴욕·새 적·관계 변화가 있어야 하는 양식은 아니다. 깨끗한 승리와 결과를 즐기는 구간도 쓸 수 있다.

## 외부 검토용으로 추릴 때

작품명·장르 → 작품 소개와 특징 → 주요 인물 → 결말을 포함한 전체 줄거리 → 원고 순서로 추릴 수 있다. 제출처가 별도 서식을 요구하면 그 서식을 사용한다. 내부 출처 검증·실행 상태·검수 메모를 모두 제출본에 넣을 필요는 없다.
