시간 구간은 우선순위 안내다. 한 작업이 빨리 끝나면 다음으로 넘어가고, 막힌 외부 설치·모델 호출을 기다리지 않는다. 예비 작업은 기능별 검색 적합성, 인물명 경계, 프롬프트 충돌, 입력 중복 방지, 실패 시 원본 보존이다.

## 이 실행의 완료 기준

- 조사 결과가 실제 실행 경로에 연결되는 코드·자료와 재현 가능한 자동 검증을 남긴다.
- 현재 운영 설정·기본 모델을 근거 없이 바꾸거나 기존 원고를 재생성하지 않는다.
- 사람의 검토는 이번 구현·검증의 필수 조건이 아니다. 기존 의견이 없을 때도 작업은 진행한다.
- 자동 구조·연속성·입력 검증을 인간 독자의 재미·상업성 검증으로 표시하지 않는다.
- 독립 Git 루트를 구별하고 기존 연구·사용자 변경을 보존한다.
