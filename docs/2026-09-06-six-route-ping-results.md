# 여섯 작성 경로 연결 핑 결과

2026-09-06. 사용자는 기획서를 수정 중이므로 기획 카나리를 금지했고, 이번 작업은 짧은 연결 확인으로 한정했다. 원문·기획서 업로드, 후보 생성, HIL 게시, 생산 모델 설정 변경은 하지 않았다.

후속 확인: `2026-09-06-hermes-grok-google-cli-followup.md`. Grok은 Hermes의 실제 터미널 호출까지 통과했다. Google은 설치된 Antigravity CLI로 Gemini 핑이 통과했으며, 기존 Gemini CLI와 구분한다. 아래 초기 시험 설명은 당시 결과를 보존한다.

최신 추론 설정은 `2026-09-06-high-reasoning-route-settings.md`를 따른다. 아래 웹 Flash·빠른·중간 및 CLI low 표기는 최초 핑 당시 기록이며 향후 기획 실행 기본값이 아니다. 웹은 최고 가용 모드로 선택했고 CLI Grok high·Gemini Pro high 지정 핑을 추가로 통과했다.

## 결과

웹 입력은 `연결 확인용입니다. 다른 작업이나 도구 사용 없이 정확히 PING_OK 만 답하세요.`였다. 실제 응답 본문에서 `PING_OK`를 확인했다. 웹 서비스에 세 개의 연결 확인 대화가 생성됐다. 기존 대화 본문을 열어 보거나 원문 자료를 보내지 않았다.

Hermes Astra는 빈 작업 디렉터리에서 safe mode와 clarify 전용 도구 범위로 호출했다. 설정을 지속 변경하지 않았으며 원작·사용자 메모리·프로젝트 규칙 주입을 피하는 진단 호출이었다. 실행 6.1초, 관측 입력 7,708토큰·출력 6토큰·API 호출 1회였다. 도구가 계산한 비용 0은 실제 무료 또는 구독 사용량 0의 증거로 해석하지 않는다. 생산 컨텍스트 전달이나 기획 품질을 검증한 것이 아니다.

Grok CLI 단독은 웹 검색·하위 에이전트·도구를 끄고 핑했다. 4.5초에 `PING_OK`를 반환했다. 모델 목록 명령에서 grok.com 로그인과 기본 모델 `grok-4.6`을 확인했다. Hermes의 `xai-oauth` 제공자는 별도 자격 증명이 없어 모델 호출 전에 중단됐다. 이 시험은 Hermes가 Grok CLI를 하위 프로세스로 실행하는 연결을 구현·검증한 것이 아니므로 두 결과를 합쳐 성공으로 표시하지 않는다.

Hermes 소스에는 Gemini native API adapter가 있으나 Gemini CLI 연결과 동등하지 않다. 확인한 로컬 위치에서 Gemini CLI 실행기는 발견하지 못했다. 따라서 Gemini를 Hermes에서 절대 사용할 수 없다는 결론도, 현재 사용 가능하다는 결론도 내리지 않는다. CLI 설치와 로그인·호출 연결은 별도 후속 작업이다. 이번에는 패키지 설치·인증 변경·API 대체를 하지 않았다.

## 이번 지시 반영

- 브라우저는 ego lite를 기본으로 사용한다. 독립 작업 공간을 사용하므로 사용자 탭과의 조작 충돌을 줄일 수 있으나, 로그인·선택 모델·서비스 UI가 항상 같다는 보장은 없다.
- 이전 Chrome의 Grok 전문가 모드와 이번 ego lite의 빠른 모드가 달랐다. 핑에서는 기존 모드를 유지했으며 실제 비교 전에 각 경로의 모드를 명시해야 한다.
- 사용자가 기획서 수정 완료 및 재개를 지시하기 전에는 연결 성공과 무관하게 기획 카나리를 실행하지 않는다.
- 현대판타지는 주요 작품 3편 묶음을 로테이션한다. 한 번의 여섯 경로 비교에서는 같은 묶음을 쓰고, 다음 비교에서 하위 유형·주축·보조 작품을 바꾼다. 재벌·투자형 세 작품을 영구 고정하지 않는다.

## 후속 순서

1. Google 개인 구독의 CLI 경로는 공식 전환 공지에 따라 Antigravity CLI를 권장한다. 실제 핑은 통과했으며 기존 Gemini CLI라는 이름으로 표시하지 않는다.
2. Grok은 Hermes → 기존 CLI 호출 핑이 통과했다. 새 OAuth 연결 없이 생산용 실행·결과 수집 래퍼를 준비할 수 있다.
3. 실제 생산 연결에서는 출력·오류 분리, 원문 보존, 경로·모델 태그, 시간 제한을 적용한다. 연결 확인만으로 기획 카나리를 실행하지 않는다.
4. 기획서 수정 완료 후 공통 입력·모드·첫 원작 묶음을 확정하고 현대판타지 여섯 기획서 비교를 재개한다.
