# 장면 선택 기록과 실제 집필 전달

2026-09-12 시간 제한 해제 후 구현. 기존 Planner 호출 안에서 독자가 보고 싶어 할 구체적 순간, 가능한 행동·상대 조건·읽는 경험·감수할 것, 선택한 후보와 이유를 짧게 남긴다. 작법 팩을 활성화한 한국어 Book에 선택적 Markdown 형식을 안내한다. 후보는 1~3개이며 비교할 이유가 없으면 하나만 적는다. 긴 사고 과정이나 항목을 채우기 위한 새 갈등을 요구하지 않는다.

원래 메모에는 모든 후보를 보존한다. 최종 메모를 기존 권한 검사로 정리한 뒤 정확한 본문 SHA를 `story/runtime/scene-decisions/<chapter>-<memo-sha>.json`에 기록한다. malformed optional 기록 때문에 Planner 호출을 더 반복하지 않는다. 필수 메모 형식의 기존 재시도 정책은 유지한다.

Composer 검색 문맥, Writer, Reviser 등 공통 메모 표현에서는 선택한 행동과 이유만 전달한다. 메모를 Composer selectedContext에서 다시 전달해 버린 후보가 복구되는 경로도 차단했다. 선택 ID 누락·중복 또는 근거 누락이면 원본에 invalid 상태를 보존하고 해당 선택 기록을 집필 지시에서 제외한다. 선택 기록은 기획이며 이미 벌어진 사건이 아니다.

## 확인한 실행

- 새 테스트 11개: 예전 메모의 동일 출력, fenced 예제 제외, 선택 ID 결속, 빈 근거·중복 후보·중복 섹션, 후보 하나, escaped pipe, 정확한 SHA, 불변 기록 충돌, optional 기록 실패에도 기존 Planner 호출이 진행되는지를 검사했다.
- 실제 Planner 메서드에 합성 응답을 주입하여 optional 오류에도 기존 한 번의 호출로 끝남을 확인했다.
- 실제 Writer의 첫 호출을 가로채서 선택한 장면은 있고 버린 후보는 없으며 메모 원본은 그대로임을 확인했다.
- Planner·Composer·Writer·Reviser·공통 메모 표현과 창작 의도 관련 8개 파일의 173개 테스트가 이 단계에서 통과했다. 이후 통합 검증은 별도 최신 영수증을 따른다.

형식과 전달 경로의 검증이다. 후보가 문학적으로 다양하거나 선택이 더 재미있다는 것을 자동으로 입증한 결과는 아니다. 실제 독자 품질 비교는 수행하지 않았다.
